# Scope: Milestone 1 - Mechanics & Statistics

## Architecture
- Implementation of 6 native custom simulation React components:
  1. `CustomBalancingAct.jsx`
  2. `CustomCollisionLab.jsx`
  3. `CustomCenterandVariability.jsx`
  4. `CustomEnergySkateParkBasics.jsx`
  5. `CustomHookesLaw.jsx`
  6. `CustomMassesandSpringsBasics.jsx`
- Location: `src/components/simulations/`
- Aesthetic: dark-mode glassmorphism, responsive controls, Lucide React icons, Canvas or SVG rendering.
- Performance: smooth 60fps Canvas/SVG animation using `useRef` for physics animation loops.
- Size constraint: >= 8KB per file. No facades or wrappers.
